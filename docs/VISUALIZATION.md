# Centaur Visualization Index

Centaur is currently an ordered Python pipeline, not a LangGraph runtime. The
architecture target is now LangGraph-first orchestration with Pydantic-backed
state and node contracts. These visual files are the documentation bridge while
the runtime is migrated.

## Current Visuals

- `docs/visuals/current_pipeline.mmd`
  - Generated from `app.engine.pipelines.build_default_pipeline()`.
  - Shows every control tick step in the actual runtime order.

- `docs/visuals/entry_decision_funnel.mmd`
  - Hand-authored conceptual graph.
  - Shows the entry path from configured symbols to candidates, signals,
    fitness allocation, CFO approval, paper execution, and the same-as-paper
    live follower gate.

- `TICK_DECISION_FLOW.md`
  - Plain-English guide with inline Mermaid diagrams and code references.

## Regenerate The Pipeline Graph

Run:

```bash
.venv-mac/bin/python scripts/export_pipeline_mermaid.py
```

That rewrites:

```text
docs/visuals/current_pipeline.mmd
```

Use this after changing `build_default_pipeline()` so the visual pipeline does
not drift from the code.

## Required LangGraph/Pydantic Migration Work

The current diagrams are documentation. They are not generated by LangGraph.

The migration should add:

```text
LangGraph StateGraph definitions
Pydantic state, node input, and node output models
explicit node/edge metadata
graph rendering/export from the runtime graph
tests that compare graph order to the old pipeline order during migration
```

Until then, the exporter script is the lightweight source-of-truth bridge from
the running pipeline to visual docs.
